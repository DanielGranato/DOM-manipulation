# ⏱️ Focus Timer — JavaScript DOM Manipulation

A productivity timer built with vanilla JavaScript as part of the React learning path at Alura.

The project explores DOM manipulation, event handling, dynamic interface updates, countdown timers, audio controls, and interaction with HTML elements using JavaScript.


<img src="./imagens/desktop-home.png">

## 🚀 Features

- Focus timer with a 25-minute countdown.
- Short break timer with a 5-minute countdown.
- Long break timer with a 15-minute countdown.
- Start and pause functionality.
- Visual changes according to the selected context.
- Dynamic title and image updates.
- Background music with play/pause control.
- Audio feedback when starting, pausing, and finishing the timer.
- Automatic timer reset when the countdown reaches zero.
- Real-time timer display.


## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Browser Web APIs
- `setInterval()`
- Audio API
